# Projects Guide

Welcome to Projects — your dedicated workspace inside Duncan for planning, collaborating, and getting things done with the help of AI.

---

## Overview

A **Project** is a self-contained workspace where you and your teammates can:

- Have ongoing AI-powered chats with Duncan about a specific topic
- Store reference documents Duncan can read from
- Keep organised notes and folders
- Track tasks and to-dos
- Push tasks onto the company Workstreams board when they are ready to be tracked at a wider level

Use a Project whenever a piece of work is bigger than a single conversation and needs its own persistent context — for example: launching a new product, running a hiring round, preparing a board pack, planning a marketing campaign, or scoping a supplier decision.

> Think of each Project as a "room" that remembers everything inside it: your chats, files, notes, and tasks all live together.

## Navigation

Click **Projects** in the left sidebar to reach the main Projects page.

### The Projects page

You will see:

- **New Project** button (top right) — starts a new workspace.
- **Project cards** — one card per project you have access to. Each card shows the project name and creation date, and indicates if the project has custom AI instructions.
- **Trash icon** (appears when you hover a card) — deletes the project.

Click anywhere on a project card to open its workspace.

[Screenshot: Projects list with hover-revealed trash icon]

### Inside a project workspace

Once inside a project, the screen is split into three areas:

1. **Chat list** (left panel, or hamburger menu on mobile) — every conversation you've had inside this project.
2. **Chat area** (centre) — where you talk to Duncan and see AI responses.
3. **Action buttons** (top right) — Files, Notes, Tasks, Collaborate, Settings.

At the top of the chat area you may also see a **Planning Checklist** widget, which collects action items suggested by Duncan or added manually.

[Screenshot: Project workspace with chats, chat area, and action buttons]

## Creating a Project

1. Go to **Projects** in the sidebar.
2. Click **New Project** (or **Create your first project** if you have none yet).
3. Enter a **Project Name** — make it descriptive (for example, *"Q3 Website Redesign"*).
4. Optionally add **Custom Instructions** — tell Duncan how to behave inside this project (its tone, focus area, priorities, or any rules to follow).
5. Click **Create**.

You'll be taken straight into the new project workspace, ready to start chatting.

[Screenshot: Create Project dialog with name and custom instructions]

> **Tip:** Custom Instructions are powerful. If your project is about a specific customer, product, or subject, tell Duncan up front — it will apply that context to every conversation in this project.

## Managing a Project

### Renaming or updating instructions

1. Open the project.
2. Click **Settings** (top right).
3. Update the **Project Name**, **System Instructions**, or **Note Template**.
4. Click **Save**.

[Screenshot: Project Settings dialog]

### Managing chats

Every project can hold multiple chats — useful for keeping separate threads (e.g. one for research, one for drafting, one for review).

- **New Chat** — click the "+ New Chat" button in the chat list.
- **Switch chat** — click any chat title in the list.
- **Rename chat** — hover a chat and click the pencil icon, or double-click the title. Press **Enter** to save, **Escape** to cancel. Duncan may also auto-generate a title after your first exchange.
- **Delete chat** — hover a chat and click the trash icon. This permanently removes the conversation.

Empty chats you never actually used are automatically cleaned up when you re-open the project.

[Screenshot: Chat list with rename and delete controls]

### Talking to Duncan

Type your message in the chat box at the bottom and press **Send** (or Enter). You can:

- Attach files to a single message using the paperclip in the composer.
- Use voice input if enabled on your device.
- Ask Duncan to reference project files, plan tasks, summarise notes, or draft anything you need.

If Duncan replies with a checklist (a list of `- [ ]` action items), you'll see a link **"Add checklist to Planning"** underneath the reply — click it to send those items straight into your Planning Checklist.

[Screenshot: AI response with 'Add checklist to Planning' link]

## Notes

Notes are for writing things down properly — meeting minutes, briefs, decisions, drafts — anything that shouldn't live inside a chat.

Click **Notes** in the top-right action bar to open the Notes drawer.

### Creating and organising

- **+ Note** (header) — creates a new blank note.
- **+ Folder** (header) — you'll be asked to name a new folder.
- **Folder menu (⋯)** on any folder — lets you:
  - **New subfolder** — nest a folder inside this one
  - **Rename** — change the folder name
  - **Delete** — remove the folder (any notes inside move back to the root)
- **Drag and drop** — drag a note onto a folder to move it there. Drag onto **"All notes"** to move it back to the root.

[Screenshot: Notes drawer with folder tree]

### Writing a note

Click a note to open it in the editor. The formatting toolbar includes:

- **H1 / H2** — headings
- **Bold, Italic, Underline** — text styles
- **Bullet list / Numbered list / Checklist** — lists (checklists support ticking items off)
- **Quote** — indented quote block
- **Code** — code block
- **Undo / Redo**

Standard keyboard shortcuts work: **Ctrl/Cmd + B** for bold, **Ctrl/Cmd + I** for italic, **Ctrl/Cmd + Z** to undo, and so on.

Notes **save automatically** as you type — there is no Save button.

[Screenshot: Note editor with formatting toolbar]

### Note actions (top of editor)

- **Paperclip** — attach files to the note (see *Documents & Attachments*).
- **Pin / Unpin** — pinned notes sort to the top of the list.
- **Move** dropdown — move the note into a different folder.
- **Trash** — delete the note.

## Tasks

Tasks are for tracking work items inside a project. They can be created by you, imported from meeting notes, or suggested by Duncan.

### The Planning Checklist (inside a chat)

At the top of the chat area you'll see the Planning Checklist for that chat. Use it to:

- **Tick a task** to mark it done. Untick to reopen it.
- **Click a title** to edit it in place.
- **Hover a row** to reveal the group label field (a short tag to group related tasks) and the trash icon.
- **Assignee picker** — click to assign the task to a teammate, or set it back to Unassigned.
- **Accept** — for tasks Duncan has suggested, click Accept to add them to your active list.
- **Quick add bar** — type a title at the bottom, optionally pick an assignee and group, then press Enter or click Add.

Click **Also send to Workstreams** to push the whole checklist onto the company Workstreams board (see *Common Workflows* below).

[Screenshot: Planning Checklist with quick-add bar]

### The Tasks drawer (project-wide)

Click **Tasks** in the top-right action bar to see every task across every chat in this project.

Controls at the top:

- **Search** — filter tasks by title.
- **Owner** filter — All / Unassigned / any teammate.
- **Due date** filter — All / Overdue / Has due date / No due date.
- **Deadline** filter — All / Overdue / Has deadline / No deadline.
- **Clear** — resets all filters (appears when a filter is active).
- **Import** — opens the Import Tasks dialog (see below).

Each task row lets you:

- **Tick the checkbox** — mark done / not done.
- **Click the title** — edit inline.
- **Owner** dropdown — change who it's assigned to.
- **Due date** picker — set or clear a due date.
- **Deadline** picker — set or clear a deadline.
- **Trash icon** (on hover) — delete the task (with a confirmation prompt).

At the bottom is a **quick-add form** — type a title, optionally set owner and due date, then click **+** or press Enter.

> **Due date vs Deadline:** Both are dates you set on a task. Use whichever convention your team prefers — for example, "due date" for the soft target and "deadline" for the hard cut-off.

[Screenshot: Tasks drawer with filters and task list]

### Importing tasks from meeting notes

The Import dialog turns meeting notes into a set of tasks automatically.

1. Click **Import** in the Tasks drawer.
2. Choose a source:
   - **Meetings mode (default)** — browse your Gmail for meeting notes (Google Meet auto-notes, Gemini notes, etc.). Use the search box, click **Search**, or click **Load more meetings** to page through. Click any email to load it.
   - **Paste notes instead** — paste notes text directly into the textarea, or upload a `.txt` / `.md` file.
3. Click **Extract action items**. Duncan will read the notes and propose a list of tasks.
4. **Tick or untick** each proposed action to include or exclude it.
5. Click **Add N tasks** to add them to your Planning Checklist.

Gmail must be connected in your Settings for the meetings mode to work — if it's not, you'll see a link to connect it, or you can use the paste option instead.

[Screenshot: Import Tasks dialog with extracted actions]

## Documents & Attachments

There are two places files can live inside a project:

### 1. Project Files (for Duncan's knowledge)

Files uploaded here become **reference material** that Duncan can read from and cite in conversations.

Click **Files** in the top-right action bar to open the Files panel.

- **Upload** — pick one or more files. Supported types include PDF, Word, text, Markdown, CSV, JSON, XML, YAML, and common image formats (JPG, PNG, WEBP, GIF).
- **Index file** — appears next to any file that hasn't been indexed yet. Indexing lets Duncan search inside the file. Files are indexed automatically after upload; use this link if indexing didn't complete.
- **Re-index icon** — re-run indexing on a file (for example, after replacing it).
- **Trash icon** (hover) — delete the file. This removes it from Duncan's knowledge too.

[Screenshot: Files panel with uploaded documents]

> **Tip:** Upload key reference documents *before* starting a conversation so Duncan can quote them accurately from the very first message.

### 2. Note attachments (for context on a specific note)

Inside a note, click the **paperclip** at the top of the editor to attach files directly to that note. Each attachment appears as a chip:

- **Click the filename** to download the file.
- **Click the ✗** to remove it from the note.

Note attachments are for you and your teammates — they are not read by Duncan the way Project Files are.

## Collaboration

### Adding teammates

1. Open the project.
2. Click **Collaborate** in the top-right action bar.
3. Select a teammate from the dropdown.
4. Click **Add**.

They'll receive an email letting them know they've been added, and the project will appear in their Projects list.

[Screenshot: Collaborate dialog with teammate dropdown]

### Ownership and removal

- The person who created the project is the **owner** and is marked as such in the members list.
- Any collaborator can be removed by clicking **Remove** next to their name.
- The owner cannot be removed from their own project.
- All collaborators can currently see and edit everything inside the project — chats, files, notes, and tasks — so add teammates thoughtfully.

### Assigning tasks

Tasks can be assigned to any project member using the assignee picker on the task row (in the Planning Checklist or the Tasks drawer). Reassign at any time by picking a different name, or clear the assignment by choosing **Unassigned**.

### Comments and mentions

Comment threads and @mentions live on the **Workstreams** board rather than inside Projects. If a task needs a wider discussion, promote it to Workstreams (see below) and use the card's Comments tab there.

## Deleting a Project

To delete a project:

1. Go to the **Projects** list.
2. Hover the project card and click the **trash icon**.
3. Confirm when prompted.

### What happens when you delete

Deleting a project is **permanent and cannot be undone**. It removes:

- All chats and chat messages inside the project
- All notes and note folders
- All note attachments
- All tasks and planning items
- All uploaded project files
- All collaborator access to the project

> **Before deleting:** if any part of the project is worth keeping (a document, a summary, a set of tasks), download or copy it out first, or promote the tasks to Workstreams.

Individual items can also be deleted on their own without deleting the whole project:

- **Delete a chat** — trash icon on the chat row.
- **Delete a note** — trash icon in the note editor header.
- **Delete a file** — trash icon on the file row.
- **Delete a task** — trash icon on the task row.

All deletions are permanent.

## Common Workflows

### Create a new project

1. Sidebar → **Projects** → **New Project**.
2. Give it a clear name and (optionally) custom instructions.
3. Add your first message in the chat to start working with Duncan.
4. Upload any reference files via the **Files** button so Duncan has context.
5. Invite teammates via **Collaborate**.

### Track project progress

1. Use the **Planning Checklist** inside chats to capture actions as they come up.
2. Open the **Tasks** drawer to see everything across the project in one place.
3. Use the **Owner**, **Due date**, and **Deadline** filters to focus on what matters this week.
4. Tick tasks off as they're completed — completed tasks stay visible so you have a record.

### Add notes and tasks

- Notes → click **Notes** → **+ Note** → write, and it auto-saves.
- Tasks → use the quick-add bar in either the Planning Checklist or the Tasks drawer.
- Meeting notes → **Tasks → Import** → pick a meeting or paste notes → **Extract action items** → **Add N tasks**.

### Collaborate with team members

1. Click **Collaborate** and add each teammate.
2. Assign tasks to the right people via the assignee picker.
3. Use one shared chat for the whole team, or spin up separate chats per workstream — whichever suits.

### Promote tasks to the company Workstreams board

When a set of tasks is ready to be tracked at company level:

1. Open the chat's **Planning Checklist**.
2. Click **Also send to Workstreams**.
3. Choose whether to create **one card for the whole project** or **one card per group**.
4. Enter a card title, pick a project tag (Lightning Strike Event, Website, K10 App, or School Integrations), and optionally set a default due date for tasks without one.
5. Click **Create cards**. You'll be taken to Workstreams to see them.

## FAQ

**Who can see my project?**
Only you and the teammates you've added via **Collaborate**.

**Can two people work in the same chat at the same time?**
Yes — messages, tasks, and notes update in real time for everyone in the project.

**Does Duncan remember previous conversations in the same project?**
Duncan remembers the context of the chat you're currently in. Separate chats inside the same project don't share memory — start a new chat when you want a fresh context, and stay in the same chat when you want continuity.

**How do I make Duncan use my uploaded files?**
Upload them via **Files**. They're indexed automatically. Then just refer to the document in your chat — for example, *"Summarise the Q2 report"* — and Duncan will pull from it.

**Why can't I see my file's contents being used?**
If a file failed to index, click **Index file** next to it in the Files panel to re-run indexing.

**What's the difference between a chat's Planning Checklist and the project-wide Tasks drawer?**
The **Planning Checklist** shows only the tasks belonging to the current chat. The **Tasks drawer** shows every task from every chat in the whole project.

**Why are there two date fields on a task — due date and deadline?**
Both are optional dates you set. Use them however your team prefers — for example, "due date" as a soft target and "deadline" as a firm cut-off.

**I set a Note Template in Settings — why doesn't it appear when I create a note?**
The Note Template is captured in project settings but is not currently applied automatically to new notes. Copy from it manually if you want to reuse the structure.

**Can I recover a deleted project, chat, note, task, or file?**
No — deletions are permanent. Please double-check before confirming a delete.

**Can I move a chat, note, or task from one project to another?**
Chats, notes, and tasks belong to the project they were created in and cannot be moved. Copy the content out manually if you need to move it.

**How do I stop being a collaborator on a project?**
Ask the project owner (or another collaborator) to remove you via the **Collaborate** dialog.

**How do I import a meeting's action items?**
Open the project → **Tasks** → **Import** → choose the meeting from Gmail or paste the notes → **Extract action items** → tick the ones you want → **Add tasks**.

**When should I promote tasks to Workstreams?**
Once the plan is stable and needs to be tracked at a company/leadership level with status colours (Red / Yellow / Green), assignees, and comments across the wider team.
